เกี่ยวกับ มิสเตอร์โบโล่

มิสเตอร์โบโล่ เป็นเว็บไซต์สาธิตสำหรับเรียนรู้การสร้างระบบขายคอร์สออนไลน์แบบครบวงจร — มีระบบสมัครสมาชิก, ตะกร้าสินค้า, การชำระเงิน (จำลอง), ใบเสร็จ, ระบบแจ้งปัญหา และหลังบ้านสำหรับผู้ดูแลระบบ

โปรเจกต์นี้ถูกสร้างขึ้นเพื่อการศึกษาและทดลองระบบ ไม่ใช่ร้านค้าจริง คอร์สทั้งหมดที่แสดงเป็นเนื้อหาตัวอย่างเท่านั้น

เทคโนโลยีที่ใช้

  • Backend: Python + FastAPI + SQLAlchemy + SQLite
  • Frontend: HTML/CSS/JavaScript (แยกจาก backend อย่างชัดเจน เรียกผ่าน REST API)
  • ความปลอดภัย: bcrypt password hashing, JWT ใน httpOnly cookie, rate limiting, CSRF protection, RBAC
